Case Study

OCR Supplier Invoice Pipeline

Automated ingestion of supplier invoices from email into a governed ERP workflow — from document to validated draft invoice.

Challenge

Manual invoice processing slowed finance operations

Finance teams spent hours manually retyping PDF invoices. Errors delayed payments, duplicates slipped through, and supplier data was inconsistent across the organisation.

Solution

An automated pipeline from inbox to ERP draft

Invoices arrive by email, are read and structured automatically, validated against business rules, and handed to the ERP as review-ready drafts — humans approve edge cases, not every line item.

Architecture

End-to-end document processing flow

Supplier Invoice PDF arrives by email from suppliers
IMAP Dedicated mailbox receives and queues documents
OCR Text extraction from PDF documents
LLM Extraction Structured fields extracted from invoice text
JSON Validation Schema checks ensure data integrity
Business Rules Cost centers, duplicates, and amount checks
Dolibarr ERP Draft supplier invoice ready for review
Technologies

Technology Stack

Python OCR LLMs JSON IMAP ERP Docker
Key Features

Key Features

  • Email-based ingestion with no external API exposure to the ERP
  • Schema-bound extraction with versioned JSON contracts
  • Duplicate detection and amount validation before posting
  • Automatic cost-center assignment through business rules
  • Human review states for edge cases and exceptions
  • Audit-friendly processing with full traceability
Outcome

Business Outcome

Improved invoice processing by reducing manual data entry, increasing traceability, and streamlining the review workflow before ERP registration.
